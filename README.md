# MindSync: An AI-Enhanced Mindfulness Journal

![Language](https://img.shields.io/badge/Language-Kotlin-7F52FF?style=for-the-badge&logo=kotlin&logoColor=white)

## Description

A privacy-first Android journaling application designed to facilitate emotional clarity and proactive mental wellness through on-device data processing and sentiment analysis.

## Features
* **Local-First Privacy:** All journal entries and generated reflections are stored entirely on-device using an encrypted Room Database. No personal thoughts ever leave the device.
* **On-Device Sentiment Analysis:** Implements a local NLP pipeline using TensorFlow Lite to analyze the emotional tone of daily entries without relying on cloud APIs.
* **Intelligent Reflections:** The "Suggestion Giver" module maps detected moods to a curated library of mindfulness reflections, offering context-aware support.
* **Modern UI/UX:** Built entirely with Jetpack Compose, featuring a calming, gradient-based Material Design 3 interface for a distraction-free experience.

## Tech Stack
* **Language:** Kotlin
* **UI Toolkit:** Jetpack Compose
* **Architecture:** MVVM (Model-View-ViewModel)
* **Database:** Room Persistence Library
* **Machine Learning:** TensorFlow Lite
